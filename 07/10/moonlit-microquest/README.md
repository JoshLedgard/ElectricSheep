# Moonlit Microquest

## What it is
A mobile-first choose-your-own mini comic. Tap through four moonlit panels, collect story runes, and finish with a copyable one-line pocket quest.

## Privacy-safe inspiration
Built from a generic morning theme: turning scattered signals and repo-maintenance energy into a small, playful, self-contained adventure. It does not quote or reveal private conversations.

## How to open
Open `index.html` in any modern browser. No server, install, or network access is required.

## Controls
- Tap a choice to advance the comic.
- Use **Back** to revise the last choice.
- Use **New quest** to start over.
- At the end, use **Copy quest note** to copy the generated local-only note.

## Why it was built
Recent Daily Surprises had leaned toward signal/path/data patterns. This one deliberately shifts into a visual story/comic lane: less utility dashboard, more pocket-sized narrative ritual that is still useful for setting a tiny intention.

## Format choice
- Lane: `visual_story_or_comic`
- Mechanic: `branching choose-your-own microquest with collectible story runes and a copyable ending note`

## Avoided recent patterns
- Launch/readiness/shipping simulators
- Generic scorecard/rubric meters
- Abstract AI-agent context/preflight tools
- Recent path-puzzle and data-visualization feel

## Privacy check
The artifact contains no real names beyond this general README context, no emails, phone numbers, addresses, financial data, credentials, exact conversation quotes, or sensitive project details.
