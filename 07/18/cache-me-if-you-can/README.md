# Cache Me If You Can — A Tiny Queueing Arcade

## What it is
A polished, pocket-sized queueing arcade presented as a fictional two-lane hardware console. Requests fall into two lanes. Hold a lane’s large pad to batch its requests, then release while its charge marker is in the green band. Flush too early and you waste the batch; wait too long and the machine heats up. Clear six deterministic waves to complete the shift.

This is a playful arcade game, not an operational simulator, benchmark, assessment, or representation of any real system. Its ordinary points and combo counter are game feedback only.

## Privacy-safe inspiration
Built from the generic feeling of calmly handling a noisy stream and deciding when to act versus when to batch. That broad theme became an entirely fictional pocket arcade. It contains no real people, organizations, projects, accounts, messages, conversations, or datasets.

The page makes no network requests and stores nothing. All play state exists only in the open browser tab.

## How to open
Open `index.html` in any modern browser. It is one self-contained HTML file with inline art, styles, audio, and game code. No server, install, package, external asset, font, or network connection is required.

## Controls
- Press and hold the large **left** or **right** pad to batch incoming requests in that lane.
- Release while the white charge marker sits in the green band.
- On a keyboard, hold/release **F** for the left lane and **J** for the right lane. Arrow keys and A/L also work.
- Use the speaker button to mute sound.
- Use the motion button to reduce animation; the page also respects the system reduced-motion preference.
- Clear all six waves for the finish state. A run lasts roughly two and a half minutes.

## Why it was built
To turn the subtle rhythm of “act now or batch?” into a tactile two-thumb game rather than another themed webpage. The goal is a surprising, immediately playable artifact with a real-feeling interface, fair deterministic escalation, and enough texture for a short morning break.
