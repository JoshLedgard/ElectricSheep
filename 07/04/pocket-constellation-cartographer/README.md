# Pocket Constellation Cartographer

## What it is
A mobile-first spatial logic puzzle where you tap stars to draw a route through a small constellation. Five handcrafted levels ask for different route shapes: visit all blue stars, avoid a nebula, collect comets before a beacon, make a loop, and finish with an exact-link morning map.

## Privacy-safe inspiration
Inspired by a generic, privacy-safe theme from recent work: turning scattered signals into a clean path. No private conversation details, names, customer information, secrets, or direct quotes are included.

## How to open
Open `index.html` in any modern browser. It is self-contained and does not need a server, network access, or package install.

## Controls
- Tap a star to select it.
- Tap a connected neighboring star to add a link.
- Use **Check route** to validate the level goal.
- Use **Undo** or **Reset** to repair the route.
- Use the level buttons or **Next** after solving.
