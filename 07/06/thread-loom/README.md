# Thread Loom

## What it is
Thread Loom is a mobile-first tiny decision-aid editor. It gives you a handful of loose thought-threads and three shelves — **Now**, **Next**, and **Later**. Tap a thread to move it through the shelves, add your own thread if you want, and watch the selected threads become a simple woven visual plus a copyable tiny plan.

It is self-contained: no server, no install, no external assets, and no network. Optional thread state is stored only in this browser via localStorage.

## Privacy-safe inspiration
Inspired by a generic recent theme: small systems become easier to act on when they are arranged carefully. The artifact does not mention or encode private chats, projects, accounts, people, quotes, emails, addresses, financial details, or sensitive specifics.

## How to open
Open `index.html` in any modern browser on phone or desktop. It works as a local file.

## Controls
- Tap or click a thread to cycle it through **Now → Next → Later → loose**.
- Use **Tab** to focus any thread button, then **Enter** or **Space** to move it.
- Type in **Add a thread…** and press **Add** to create a local custom thread.
- **Gentle shuffle** gives the loose starter threads a first arrangement.
- **Copy plan** copies the generated Now/Next/Later note when clipboard access is available.
- **Reset** restores the starter threads.
