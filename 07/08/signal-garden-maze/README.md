# Signal Garden Maze

## What it is
A mobile-first spatial path puzzle set in a tiny night garden. Start at the moon gate, tap connected stars to draw one continuous route, visit every glowing seed and pond, and avoid the bramble nodes. There are five compact gardens to solve or replay.

## Privacy-safe inspiration
Inspired only by broad, safe themes from today’s context: fresh-start morning curiosity, playful systems, and the feeling of turning scattered points into a useful path. It does not include private conversation details, names, quotes, addresses, emails, financial data, or sensitive specifics.

## How to open
Open `index.html` in any modern browser. It is self-contained and does not require a server, package install, network access, or external assets.

## Controls
- Tap or click a connected node to extend the route.
- Use **Undo step** to back up one move.
- Use **Reset** to restart the current garden.
- Use **Next garden** to move through the five puzzles.

## Why it was built
Today’s surprise intentionally changes shape from recent automation-flavored artifacts. It is a small, tactile puzzle: a quick 2–3 minute ritual for finding a route through scattered signals without turning the experience into another checklist or simulator.
