# Commit Creature Field Guide

## What it is
A tappable micro-zine — a tiny "pocket naturalist" field guide to five creatures
that live in a morning's worth of work: **Spark, Tangle, Bridge, Polish,** and
**Rest**. Each creature is an illustrated, animated comic panel with field notes,
a habitat strip, and one small one-line ritual to carry with you. You page
through it like a little zine; it is understandable in about 20 seconds and
pleasant to browse for a couple of minutes.

It is **not** a simulator, readiness checker, scorecard, rubric, preflight tool,
context debugger, or generator. Nothing is measured, scored, or submitted — you
just meet the creatures.

## Privacy-safe inspiration
The general, non-specific feeling of turning scattered work signals into a small,
understandable story — a bit of morning curiosity and a fondness for playful
systems. The creatures represent generic, universal work *moods* (a fresh spark,
a tangle, a connection, a polish, a rest), with entirely synthetic naming. No
real people, organizations, projects, accounts, messages, or any private details
appear anywhere.

## How to open
Double-click `index.html`, or open it in any modern browser. It is a single
self-contained local file — no build step, no installation, and no network or
internet connection required.

## Controls
- **Next › / ‹ Back** buttons to turn pages (start-over wraps from the last page).
- **Dots** at the bottom jump directly to any page (cover + five creatures).
- **← / → arrow keys** turn pages; all controls are keyboard-focusable with
  visible focus rings and accessible labels.
- **Swipe left / right** on touch screens to page through.

## Why it was built
Part of Josh's Daily Surprise — one small, self-contained, understandable-in-a-
glance thing per day. Today's aim was a warm, low-stakes moment of morning
curiosity: give the ordinary emotional weather of getting things done a gentle,
illustrated shape, with a tiny actionable ritual on each page. It is meant to be
read once with a smile, not used as a tool.

## Format choice
- **Lane:** visual_story_or_comic
- **Mechanic:** A tappable micro-zine / field guide. The user pages through
  illustrated creature cards representing generic workflow moods (spark, tangle,
  bridge, polish, rest). Each panel animates and offers a single one-line ritual.
  It is deliberately *not* a simulator, readiness checker, scorecard, rubric,
  preflight, context debugger, or generator — just an illustrated guide you read.

## Avoided recent patterns
To stay fresh against recent surprises, this deliberately avoids:
- launch / readiness / shipping simulators
- scorecard / rubric / meter interfaces
- abstract AI-agent context / preflight / debugger tools
- spatial routing / path puzzles (e.g. Signal Garden)
- card-sorting boards (e.g. Thread Loom)
- ambient signal-rainfall timelines (e.g. Signal Rain Almanac)
- generic generators

Instead it leans fully into a distinct comic / zine format: bold ink panel
frames, halftone paper grain, hand-drawn animated SVG creatures, and a
page-turning naturalist layout.
