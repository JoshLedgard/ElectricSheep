# Signal Safari

## What it is

Signal Safari is a tiny mobile-first visual puzzle. Each round gives a clue, and you tap abstract interface tiles that match the pattern. The toy is meant to be solved in a couple of minutes: three clues, a little feedback, and a final reveal.

## Privacy-safe inspiration

Inspired by a generic recent theme: scanning visual evidence, finding small signals, and turning messy-looking UI patterns into quick insight. It uses only abstract shapes and does not include private project details, quotes, names, customers, or data.

## How to open

Open `index.html` in any modern browser. No server, package install, or network connection is required.

## Controls

- Tap or click a tile when it matches the current clue.
- Use **Next clue** after all matches in a round are found.
- Use **Restart safari** to replay from the first clue.
- Buttons are large enough for touch and can be reached by keyboard focus.

## Why it was built

Josh’s daily surprise should feel varied and handcrafted, not like another readiness dashboard. This one is a compact puzzle about changing lenses: position, path, and negative space.
