# Pocket Signal Cartographer

## What it is

A mobile-first spatial data visualization toy for sorting tiny idea signals. Drag or tap signal chips onto a two-axis map — **Useful ↔ Playful** and **Now ↔ Later** — then watch the map draw a route and summarize the pattern.

## Privacy-safe inspiration

Inspired by a generic recent theme: making concise product artifacts, keeping outputs minimal-but-useful, and using visual confirmation instead of vague claims. No private conversation details, names, client specifics, or exact quotes are included.

## How to open

Open `index.html` in any modern browser. It is self-contained and needs no server, package install, or network connection.

## Controls

- Drag a signal chip onto the map, or tap a chip and then tap the map.
- Use **Shuffle signals** to get a fresh layout.
- Use **Reset map** to start again.
- The route and summary update as signals move.
