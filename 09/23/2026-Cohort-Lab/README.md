# Cohort Lab: 100 Users, 12 Weeks

## What it is

A tactile, self-contained product prototype that lets you run the same 100 synthetic users through a simplified 12-week SaaS cohort. Adjust onboarding friction, weekly usefulness, referral lift, and pricing pressure; then watch individual users move among New, Active, Delighted, and Churned states. A retention curve and live metrics make each run easy to compare.

This is an intuition toy, not a forecast or business model. Every person and value in it is synthetic.

## Privacy-safe inspiration

Inspired by the broad, non-private theme of building products through playful systems: make an invisible dynamic visible, direct, and easy to poke. It does not use personal data, conversation excerpts, private analytics, names, or project details.

## How to open

Open `index.html` in any modern browser. It is a single offline file with no server, install, dependency, account, or network request.

## Controls

- Choose **Leaky bucket**, **Sticky niche**, or **Referral spark** for a starting condition.
- Adjust the four sliders to change the product forces.
- Press **Run 12 weeks** to animate the whole cohort, or **Step 1 week** to inspect it slowly.
- Press **Pause** or **Reset** at any time.
- Tap or click a user dot to inspect that synthetic user's current state and useful weeks.
- Re-running uses the same deterministic cohort, so parameter changes are meaningfully comparable.

## Why it was built

Retention models usually arrive as spreadsheets or polished forecasts. Cohort Lab turns the same class of question into a small physical-feeling experiment: change one force, replay the exact cohort, and watch where behavior diverges. The aim is useful intuition in two or three minutes—not false precision.

## Format choice

- **Lane:** `data_visualization` — presented as a real-feeling product prototype / fake app.
- **Mechanic:** Tactile agent-based cohort simulation with direct parameter controls, deterministic replay, animated state transitions, presets, week stepping, and a live retention curve.
