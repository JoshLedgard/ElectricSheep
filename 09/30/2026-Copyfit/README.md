# Copyfit — The Tiny Interface Copy Game

## What it is

Copyfit is a five-round, browser-based copy-editing game. Each fictional interface starts with too many words for its real rendered slot. Tap phrases to cycle through tighter edits, preserve the promises shown beneath the interface, and make the copy physically fit. Finish all five rounds to produce a local shift receipt.

## Privacy-safe inspiration

It was inspired by a broad interest in making dense product communication clearer and turning practical interface craft into something tactile and playful. The scenarios are fictional and generic; no personal or project-specific material is used.

## How to open

Open `index.html` in any modern browser. It is a self-contained file with no server, package install, account, tracking, or network connection required.

## Controls

- Tap or click a phrase to cycle through authored shorter alternatives.
- Watch the live component: red means it overflows; green means it fits and retains its required ideas.
- Use **Reset** to restore the current round.
- Use **Stamp & continue** after a valid fit.
- At the end, restart or print the locally rendered receipt.
- Phrase controls and action buttons are keyboard accessible.

## Why it was built

Interface copy has physical consequences. Copyfit makes that usually invisible constraint visible and playable: every edit changes a real rendered component rather than an abstract score.

## Format choice

- **Lane:** Weird playable game with a useful product-writing core
- **Mechanic:** Tap-to-cut and swap words under live spatial pressure across five fixed interface-copy rounds. Browser overflow measurement determines fit; authored concept constraints preserve meaning.
