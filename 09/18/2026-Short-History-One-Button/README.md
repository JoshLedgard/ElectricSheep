# A Short History of One Button

## What it is

A one-button, eight-era interactive micro-comic. Each press moves the same button from stone, steam, and elevators through keyboards, glass, invisible interfaces, prediction, and a speculative future pause. The story is linear—there are no branches or alternate endings—and the visual system transforms with every era.

## Privacy-safe inspiration

Inspired by a generic curiosity about how familiar interfaces change over time and how one tiny interaction can carry different meanings. It uses no private conversation, person, customer, company, project, or personal detail.

## How to open

Open `index.html` in any modern browser. It is a single self-contained file with no server, dependencies, account, internet connection, or external assets.

## Controls

- Press the large central button to move forward one era.
- Use the left and right arrow buttons to revisit an era.
- Tap any segment in the eight-part timeline to jump directly to that scene.
- Keyboard users can use Left/Right Arrow; all controls have visible focus states.
- Motion is reduced automatically when the browser requests reduced motion.

## Why it was built

Instead of another utility or editable-text surface, this is a tiny linear visual story whose single repeated action changes meaning. It is meant to feel like discovering a compact future museum exhibit in a browser.

## Format choice

- **Lane:** `visual_story_or_comic`
- **Mechanic:** linear repeated-button interaction that transforms one interface across eight fixed eras

## Explicit bans avoided

This is not a field guide, atlas, almanac, codex, zine, or pocket guide. It is not choose-your-own, branching, a microquest, or a multiple-ending story. It uses no signal, cartographer, constellation, routing, or path-connection metaphor. It is not a launch/readiness/shipping simulator, scorecard, rubric meter, AI-agent context tool, preflight, debugger, or generic generator. It contains no family, travel, baseball, home, Seattle, or local-utility theme.

## Privacy check

The artifact contains no real names, email addresses, phone numbers, addresses, financial details, customer data, exact conversation quotes, analytics, network requests, or persistent storage. All text and visuals are invented and bundled in the file.
