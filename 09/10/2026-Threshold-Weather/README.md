# Threshold Weather

## What it is

A self-contained, tactile data visualization for exploring how continuous demand can create sudden operational changes at thresholds. Drag a synthetic seven-day workload curve and a capacity boundary, then compare a smoother response.

## Privacy-safe inspiration

Inspired by the general challenge of understanding operational thresholds and non-linear effects. All values are invented, neutral units; the page contains no personal, customer, company, billing, or conversation data. It runs entirely in the browser with no network requests or analytics.

## How to open

Open `index.html` in any modern browser. No server, package install, account, or internet connection is required.

## Controls

- Drag any white daily-demand point vertically with touch, mouse, or pen.
- Drag the amber dashed capacity threshold, or use its slider.
- Keyboard: tab to a point or threshold and use the Up/Down arrows.
- **Calm**, **Front**, and **Rising** load three synthetic scenarios.
- **Compare** overlays a smoothed response; **Reset** restores the current scenario.

## Why it was built

Averages often conceal the interesting part of a system: the exact places where a tiny input change produces a qualitatively different response. This prototype turns that idea into something you can feel directly rather than read about.

## Format choice

- **Lane:** `data_visualization` / product prototype (future-feeling analytical app)
- **Mechanic:** direct touch-drag manipulation of a seven-day synthetic workload waveform and an adjustable capacity threshold, with an optional smooth-response overlay
