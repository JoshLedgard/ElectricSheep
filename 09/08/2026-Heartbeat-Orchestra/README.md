# Heartbeat Orchestra

## What it is

Heartbeat Orchestra is a self-contained four-track rhythm instrument disguised as a tiny animated band. Start with the built-in groove, tap the 16-step patterns, mute performers, change the tempo, or let the band make a few controlled mutations.

## Privacy-safe inspiration

It was inspired by a general interest in coordinated autonomous systems: independent performers can keep their own rhythms while contributing to shared timing and state. No conversation, person, company, or private project is represented.

## How to open

Open `index.html` in any modern browser. It needs no server, account, package install, assets, or network connection. Audio begins only after pressing **Play** or activating a beat, in line with browser audio rules.

## Controls

- **Play / Pause** — starts or stops the sequencer.
- **Beat pads** — tap any square to toggle that beat.
- **Performer buttons** — tap to cycle each performer through active, muted, and solo states. This works equally with touch, mouse, or keyboard.
- **Tempo** — moves from 64 to 168 BPM.
- **Evolve** — changes only a handful of beats, preserving the recognizable groove.
- **Surprise** — creates a fresh playable pattern.
- **Clear** — empties the stage so you can compose from scratch.

Patterns and tempo are saved locally in the browser when storage is available. All sound is synthesized with the Web Audio API; there are no samples or remote requests.

## Why it was built

A rhythm instrument is an unexpectedly tangible way to play with independence, coordination, mutation, and shared timing. It is meant to be understood in seconds and enjoyed for a few minutes—not configured like a dashboard.
