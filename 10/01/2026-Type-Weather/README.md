# Type Weather

## What it is

Type Weather is a self-contained kinetic-typography instrument. It turns real typing cadence into an animated climate: quick bursts create wind, pauses collect as fog, corrections raise pressure, and punctuation sends visible fronts across the composition. A short performance can be recorded, replayed at its original rhythm, frozen, restyled, and exported as PNG or SVG.

## Privacy-safe inspiration

It was inspired by a broad interest in polished interfaces, expressive product prototypes, and turning normally invisible interaction details into something tactile and surprising. It does not represent any real person, project, company, customer, or private conversation.

## How to open

Open `index.html` in a modern browser. It is one self-contained file and requires no server, package install, account, network connection, or external assets.

## Controls

- **Type in Performance Text:** cadence, pauses, punctuation, and backspaces shape the stage.
- **Phrase starters:** perform a built-in phrase automatically, especially useful on phones.
- **Record take / Stop recording:** capture the text states and exact timing of a short performance.
- **Replay:** reproduce the recorded typing rhythm.
- **Freeze frame / Unfreeze:** pause or resume atmospheric motion.
- **Clear:** reset the instrument and recorded take.
- **Aurora / Storm / Paper:** change art direction while preserving the current words and performance state.
- **Save PNG / Save SVG:** export the current composition locally.

## Why it was built

Typing is usually treated only as input. Type Weather treats it as a physical performance. The words matter, but so do hesitation, revision, speed, and impact—giving a familiar interaction a visual instrument panel and a useful export loop.

## Format choice

- **Lane:** Creative coding instrument / future-artifact fake app
- **Mechanic:** Live keystroke timing, pauses, corrections, and punctuation drive kinetic typography and atmospheric particles; users can record and replay exact cadence, freeze a frame, restyle it, and export the result.

This is structurally distinct from the previous three surprises’ copy-tightening game, timed drag-and-archive game, and screenshot color inspector.

## Privacy and accessibility

Everything runs locally. The page makes no network requests, stores no text, and includes no analytics. It contains no real names, emails, phone numbers, addresses, financial data, credentials, private quotations, or personal details. Controls are keyboard accessible, primary targets meet a 44px goal, status changes use a live region, the layout is designed for a 390px viewport without horizontal overflow, and reduced-motion preferences substantially limit particle motion and accelerate recorded replay.
