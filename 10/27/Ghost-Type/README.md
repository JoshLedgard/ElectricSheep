# Ghost Type

Daily Surprise · October 27, 2026

## What it is
A ten-round offline memory-proofreading game. Study a phrase, then find the single changed character and tap to restore it. There is no timed pressure while solving, and a hint reveals the original if needed.

## Privacy-safe inspiration
The playful satisfaction of spotting a tiny inconsistency in fictional interface copy. No real personal context or private data appears in the game.

## How to open
Open `index.html` directly in a modern browser, including `file://` while offline. No server, installation, login, or network needed.

## Controls
Tap **Start game**. Each original phrase appears for about three seconds, then returns with one character altered. Tap the altered letter; an incorrect tap gives feedback without ending the round. **Show original** reveals the reference. **Next phrase** advances; **Play again** resets after the last phrase. Keyboard users can Tab through letter buttons and press Enter/Space. The original phrase is deliberately shown in uppercase; punctuation is not part of the selection.

## Why it was built
A tiny game that turns proofreading into a tactile memory challenge, with a complete beginning, progression, hint, and satisfying end rather than a generic generator.

## Format choice
- **Lane:** `game_or_puzzle`
- **Mechanic:** brief visual memorization followed by touch/keyboard character spotting and one-character correction across ten authored rounds.

## Explicit bans avoided
No field guide, zine, atlas, almanac, codex, branching adventure, choose-your-own story, microquest, signal routing/cartographer/constellation/path-connection metaphor, launch/readiness simulator, scorecard/rubric meter, abstract AI-agent preflight, or generic generator. No family, travel, baseball, or local utility framing.
