# Loop Cutter

Daily Surprise · October 30, 2026

## What it is
An offline pocket audio workbench. Listen to a four-second synthesized demo or open your own local audio, drag the waveform edges to select a moment, audition it on repeat, and download an uncompressed 16-bit PCM WAV of the selected segment. Imported audio never leaves the tab. Raw loop cuts may click at the join; move either edge until the repeat sounds right.

## Privacy-safe inspiration
The general satisfaction of turning a fleeting sound into something editable and portable. No personal conversation, sound recording, or private data was used in the sample.

## How to open
Open `index.html` directly in a modern browser, including from `file://`. There is no server, installation, account, external asset, or network call. Audio playback needs a user tap. To preserve an edit, download its WAV before closing the tab.

## Controls
Open audio to import a local file (25 MB maximum; three-minute maximum), or Restore demo. Drag either gold waveform edge to change the start/end, or use the numeric second fields for precise keyboard-accessible editing. Play loop / Pause auditions the selected interval repeatedly; Stop resets playback. Download WAV exports the exact selected samples, up to 40 MB. Playback pauses when the tab is hidden. The waveform visual is supplemental: the numeric controls perform the same edits.

## Why it was built
A small but real creative utility: a tactile edit with an actual file to keep, not a decorative demo.

## Format choice
- **Lane:** `practical_micro_tool`
- **Mechanic:** import or synthesize audio → drag trim handles or edit exact times → loop audition → export PCM WAV. Unlike the preceding teleprompter, timeline, and proofreading game.
