Echo Ledger

What if each new signup invited someone else? Set up two hypothetical referral loops, then see how each day compounds. This is a model, not a forecast or observed data.

Daily values and calculation

New signups on day d = new signups on day (d − delay) × share fraction × invites per sharer × conversion fraction. Day 0 is the starting cohort; days without a matching predecessor have zero new signups. The chart compares daily arrivals, while totals add days 0–29.
