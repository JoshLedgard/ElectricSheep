# Cueglass

Daily Surprise · October 29, 2026

## What it is
A pocket teleprompter for rehearsing a short script. Edit words, adjust scroll speed and type size, flip the lettering for a physical mirror rig, expand the stage, and scrub to a new position. A fictional sample is ready to play. All functionality is self-contained in one HTML file.

## Privacy-safe inspiration
Inspired by the general idea that writing sometimes needs to be spoken aloud to become useful. The sample is invented; it contains no personal context.

## How to open
Open `index.html` directly in a current browser, including offline from `file://`. No install, server, account, network, or microphone permission is required. Text is saved in this browser's local storage when available, never uploaded. Download a `.txt` copy if you want a portable backup.

## Controls
Edit the script above the stage. **Play/Pause** runs the scroll; **Restart** returns to the beginning. Set **Speed** from 15–180 pixels per second, and **Type size** from 22–70 pixels. **Position** scrubs the script. **Mirror** flips text horizontally for a reflection rig. **Expand stage** fills the device screen with dedicated Play/Pause and Exit controls. You can manually scroll at any time. **Load sample** and **Clear script** confirm before overwriting your words. **Download .txt** saves your current text. Outside form controls, Space plays/pauses, Up/Down changes speed, Home restarts, and Escape exits the expanded stage. The page pauses when hidden.

## Why it was built
A writing aid that turns a draft into a physical rehearsal instrument instead of scoring it or generating more copy.
