# Gearprint

Daily Surprise · November 3, 2026

## What it is
An offline rolling-gear pen plotter. Set an outer ring, an inner gear and a pen distance, then watch a mathematical curve appear. Stack up to twelve differently colored passes and export the actual vector paths as an SVG. It is a drawing instrument, not an image generator or a screenshot export.

## Privacy-safe inspiration
The broad pleasure of seeing a small mechanical rule become a tangible artifact. All starting settings and artwork are invented locally; no private context or data is included.

## How to open
Open `index.html` directly in a modern browser, including `file://` offline. No install, account, server, external assets or network is required. Nothing is uploaded or stored; save an SVG if you want to keep a print.

## Controls
- **Petal / Orbit / Lace:** load three starting arrangements and draw from scratch.
- **Outer ring teeth / Rolling gear teeth / Pen distance:** change the geometry for the next pass. The outer ring must exceed the inner gear.
- **Drawing speed:** change how quickly the pen advances.
- **Ink swatches:** choose the color of the next pass.
- **Draw anew:** erase the old print and draw the current settings. **Add a pass:** overlay another curve without erasing the previous ones. **Pause / Resume:** stop or continue the pen.
- **Save SVG:** download the currently drawn vector paths, even if a pass is not finished. On devices requesting reduced motion, a completed print is shown without waiting for animation.

## Why it was built
A pocket-sized machine for discovering how surprisingly intricate forms can arise from only a few physical ratios. The vector export turns exploration into something you can actually use.

## Format choice
- **Lane:** `calm_creative_ritual` (creative-coding instrument).
- **Mechanic:** animate a rolling-gear pen by adjusting discrete tooth counts and pen distance, overlay ink passes, and export vector paths. Not image redaction, direct reaction–diffusion painting, or cohort-grid editing.
