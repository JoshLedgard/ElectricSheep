# Ink Chamber

Daily Surprise · November 1, 2026

## What it is
A living ink instrument built on a real two-ingredient Gray–Scott reaction–diffusion simulation. Paint a new drop and watch local chemical rules turn it into branching lace, spots, or curling ribbons. Take home a PNG snapshot.

## Privacy-safe inspiration
Inspired by the general idea of making invisible behavior tangible. All colors, seeds, and simulation data are created locally in the page; no personal material is included.

## How to open
Open `index.html` in a modern browser, including directly from `file://` while offline. No installation, server, account, external assets, storage, or network access is required. The simulation starts with three small drops.

## Controls
- Drag or touch the canvas to add reactive ink. Use the brush slider to adjust radius, or toggle Eraser to remove it.
- Choose Coral, Spots, or Maze to change reaction parameters without deleting current ink. Patterns take time to develop; wait several seconds to see the effect.
- Pause / Resume controls motion; Step once advances four numerical cycles. Reset restores the starting drops without changing the selected recipe.
- Save PNG downloads the current canvas at 320 × 240 pixels. Save before leaving the page; simulation state does not persist.
- The page pauses automatically if the tab becomes hidden.

## Why it was built
An actual numerical process can become an approachable tactile creative instrument: a small change of paint or parameters makes surprising shapes without relying on a generic prompt generator.
