# Dither Studio

Daily Surprise · November 5, 2026

## What it is
An offline pixel-print workbench: load an image or work with a fictional built-in sample, choose ordered dots, Floyd–Steinberg error diffusion, or flat palette mapping, adjust ink and pixel size, compare before/after, and export a processed PNG.

## Privacy-safe inspiration
Inspired by the broad pleasure of making a visual artifact tangible. The sample art is invented and contains no personal context.

## How to open
Open `index.html` directly in a modern browser, including via `file://`. No install, server, account, or network is needed. Imported images stay in the tab and are not uploaded; nothing is stored after you close it.

## Controls
Open an image (8 MB maximum) or use sample art. Change Dither method, Ink palette, and Pixel size to process it. Drag the Reveal slider to compare processed left with original right. New sample colors produces a fresh fictional sample. Download PNG exports only the processed picture. The workspace and exported image are 480 × 360; imported images fit inside it without cropping. Transparent imports are composited onto white.

## Why it was built
It turns image-processing algorithms into a small, directly useful creative instrument with an exportable result.

## Format choice
- **Lane:** `practical_micro_tool`.
- **Mechanic:** local image import or synthetic sample → palette-based pixel dithering → touch-slider comparison → flattened PNG export. Distinct from the recent arcade physics, rolling gear drawing, and image-cover redaction.
