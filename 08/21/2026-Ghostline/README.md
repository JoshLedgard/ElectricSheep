# Ghostline — A Vanishing Teleprompter

*Daily Surprise · 2026-08-21*

## What it is

Ghostline is a self-contained rehearsal instrument for turning a short script into something you can deliver without staring at it. A fictional demo passage is ready at startup. Read it with the continuous teleprompter, tap words to preserve them as anchors, then advance through four visibility stages that progressively remove the supporting text while leaving your chosen phrases behind.

The large thumb pad controls speed and direction directly. Cruise mode can hold the selected speed, while progress and estimated reading time stay visible. The script can be edited or replaced with pasted text and downloaded as a local text file.

Everything runs in the current browser tab. Ghostline has no external assets, network requests, account, analytics, persistence, upload, camera, microphone, or recording.

## Privacy-safe inspiration

The broad inspiration was the generic craft of clear communication, polishing an idea, and following work through to a confident finish. That theme became a fictional rehearsal device without using or referring to any real person, organization, project, customer, account, message, conversation, or source material.

## How to open

Open `index.html` in any modern browser. No server, package installation, account, or internet connection is required.

## Controls

- Press **Play** or use **Space** to start and pause.
- Hold or drag the large thumb pad upward or downward to control forward and reverse speed.
- Enable **Cruise** to keep the current speed after releasing the pad.
- Tap words in the reader to mark or unmark anchor phrases.
- Move among the four rehearsal stages to progressively fade non-anchor words.
- Open the script editor to replace the demo passage, restore the demo, clear anchors, or download the current text.
- Adjust type size, phosphor theme, contrast, and motion in settings.
- Use the displayed keyboard controls for hands-free rehearsal.

## Why it was built

To make a genuinely useful, camera-free speaking practice tool with a physical-feeling interaction and a complete two-to-three-minute rehearsal arc. Instead of grading a performance, Ghostline gradually removes the script and lets memory take over.

The included passage is invented and neutral. User text remains in memory in the current tab and is not stored or transmitted. Downloading creates a plain-text file locally through the browser.
