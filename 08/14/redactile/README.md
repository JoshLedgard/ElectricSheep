# Redactile — A Screenshot Privacy Workbench

*Daily Surprise · 2026-08-14*

## What it is

Redactile is a self-contained screenshot privacy workbench with real local output. Open, paste, or drop an image; paint genuine pixelation or opaque blackout strokes onto it; add and reposition numbered callouts; compare the edited image with its original; then export a flattened PNG. A harmless fictional interface is loaded at startup so the full workflow is ready to try immediately.

Pixelation is baked into the image pixels rather than applied as a reversible CSS effect. Redactions and callouts are also flattened into the exported file.

## Privacy-safe inspiration

The generic inspiration was the recurring need to share visual evidence clearly while keeping irrelevant details private. That broad operational theme became a local visual utility without using any real people, organizations, projects, messages, conversations, accounts, or source screenshots.

Everything runs in the current browser tab. There are no uploads, network requests, accounts, analytics, external assets, or persistence.

## How to open

Open `index.html` in any modern browser. No server, installation, package, account, or internet connection is required.

## Controls

- Use **Open image**, paste from the clipboard, or drop an image onto the work area.
- Choose **Pixelate** or **Blackout**, set the brush size, then draw directly on the image with touch, pen, or pointer.
- Choose **Add callout**, tap to place a numbered marker, and drag it to reposition it.
- Use **Undo** and **Redo** to revise the edit history.
- Press and hold **Compare** to reveal the untouched original temporarily.
- Use **Reset** to restore the current image or return to the built-in fictional demo.
- Use **Export PNG** to download the flattened result.

## Why it was built

Useful screenshots often need one more pass before they are safe and easy to understand. Redactile makes that pass tactile, fast, transparent, and entirely local—while demonstrating a surprisingly complete image-editing workflow in one portable HTML file.

## Format choice

- **Lane:** `practical_micro_tool` — presented as a polished, real-feeling local browser app and future artifact.
- **Mechanic:** import, paste, or drop an image; paint destructive pixelation or solid-redaction strokes directly onto a canvas; add movable numbered callouts; undo/redo; press-and-hold to compare; and export a genuinely modified PNG.

This lane and interaction differ from the recent writing workbench, responsive-layout studio, and one-thumb rhythm game.

## Privacy check

The built-in specimen is wholly fictional and contains no real names, emails, phone numbers, addresses, credentials, financial data, organizations, conversations, analytics, or private source material. User-selected images are processed only inside the open tab and are never transmitted by Redactile.
