# Frame Shift — A One-Panel Time Comic

*Daily Surprise · 2026-08-05*

## What it is

Frame Shift is a self-contained, illustrated time comic that holds its camera on one fictional overnight studio. Scrub a 24-notch wheel and the same desk continuously transforms: blank space gathers marks, marks fold into paper, failed shapes leave useful parts, mechanisms assemble, and morning finds a tiny luminous bird occupying real space.

This is a fixed, authored arc with no branches, choices, scoring, or generated material. The scene is built from original inline SVG; its objects, room light, window, clock, captions, and layered artifacts all move with the time control. It includes automatic playback, keyboard control, reduced-motion support, and optional synthesized ticks that remain off until explicitly enabled.

Everything runs locally in the open browser tab. There are no external assets, network requests, accounts, uploads, analytics, packages, saved browser data, or server.

## How to open

Open `index.html` in any current browser. No install, account, network connection, or local server is required.

## Controls

- **Drag the time wheel** to move continuously through the night.
- **Arrow keys** move the focused wheel in precise increments.
- **Play / pause** runs the fixed sequence automatically.
- **Four chapter buttons** jump to space, rough work, loose pieces, or the completed morning object.
- **Sound off / on** enables an optional local Web Audio tick and final chime after a user gesture.
- The layout supports touch and pointer input; every control has a mobile-sized target.

## Why it was built

A one-panel comic makes change tangible without turning it into a dashboard or checklist. Holding the viewpoint steady means the story must live in material transformations rather than navigation: the user notices which marks survive, which failures return as parts, and how the room itself yields from night to morning. It is a small demonstration of what a dependency-free interactive illustration can do—not merely a themed webpage.

## Format choice

- **Lane:** `visual_story_or_comic` — a polished non-branching interactive illustration and future artifact. This lane was absent from the last three successful surprises and is used only once in the current seven-day window.

This differs structurally from the recent two-state interface manipulation, diff-to-textile visualization, and timed freehand recall painting.
