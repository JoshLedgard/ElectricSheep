# Squint — A Screenshot Attention Darkroom

*Daily Surprise · 2026-08-24*

## What it is

Squint is a self-contained, local screenshot-perception workbench. Drop, paste, or choose a screenshot, then look at it through five adjustable perception passes: squint blur, grayscale, thumbnail distance, contrast isolation, and peripheral falloff. A movable aperture lets you compare one focused region against the altered frame.

Three fictional demo compositions make the tool ready immediately. When you find an interesting view, **Print contact sheet** creates a genuine local PNG containing the original, four isolated passes, and your current mix.

Squint is a perception aid for discussing visual hierarchy, not an accessibility compliance test. It does not replace contrast checks, structural inspection, usability research, or testing with people.

Everything runs in the current browser tab. There are no dependencies, external assets, network requests, accounts, analytics, persistence, uploads, camera, or microphone. Images you load are decoded in memory and disappear when the tab closes.

## Privacy-safe inspiration

The broad inspiration was the generic craft of reviewing interfaces and making visual quality easier to perceive. That theme became a fictional local darkroom without using or referring to any real person, organization, product, project, message, conversation, customer, account, or source data.

## How to open

Open `index.html` in any modern browser. It works directly from `file://`; no server or installation is required.

## Controls

- Start with any fictional demo composition, or use **Choose image**, **Paste from clipboard**, drag-and-drop, or the system paste shortcut.
- Tap a **developing bath** for a useful preset, then adjust the five perception dials.
- Drag the aperture across the image. Arrow keys move it when its handle is focused; `[` and `]` resize it.
- Toggle **Clear window / Blur spot** to invert the aperture treatment.
- Hold **Hold: original** (or press `O` away from form controls) to peek at the untouched image.
- Use **Print contact sheet** to download a six-frame PNG assembled entirely in the browser.

## Why it was built

Visual hierarchy is easier to discuss when it can be manipulated directly instead of reduced to a checklist. Squint turns familiar perception tricks into one tactile local instrument and leaves the interpretation to the person using it.
