# Underflow — The Page Beneath the Page

*Daily Surprise · 2026-08-17*

## What it is

Underflow is a self-contained, linear interactive visual story about a fictional web page whose missing content is still present beneath its visible surface. The page opens like a theatrical architectural cutaway: scrub through six scenes, drag or hold the peel control to separate its layers, and tap small illuminated details to reveal what the composition was hiding. The sequence has one beginning, one ending, and a repaired final composition.

Everything is handcrafted in one local HTML file using inline SVG, CSS, and JavaScript. It has no dependencies, account, server, analytics, persistence, external assets, or network requests.

## Privacy-safe inspiration

The broad inspiration was visual quality work and the strange moment when interface content exists but has been clipped, covered, or pushed outside its intended frame. That generic theme became a wholly fictional stage set. It does not use or refer to any real person, organization, website, project, message, conversation, account, or source material.

## How to open

Open `index.html` in any modern browser. It works directly from `file://`; no installation or internet connection is required.

## Controls

- Select **Enter the cutaway** to begin.
- Swipe vertically on the stage, use a mouse wheel, or drag the large timeline scrubber to move through the single linear sequence.
- Use **Arrow keys**, **Page Up/Down**, **Home**, and **End** when the scrubber is focused.
- Hold or drag **Peel** to temporarily separate the visible page from the layers beneath it.
- Tap illuminated `+` details when they appear for small deterministic reveals.
- Use **Replay** to return to the beginning.

All controls have touch-friendly targets. The experience supports reduced-motion preferences and does not rely on hover.

## Why it was built

To turn a familiar interface failure into an unexpected miniature piece of stagecraft: less documentation, more tactile x-ray theater. It explores how a browser can explain its own hidden geometry through motion while remaining immediate enough to enjoy in a few minutes.
