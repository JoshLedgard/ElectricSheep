# Foldline — Responsive Choreography Studio

## What it is

Foldline is a self-contained future-product prototype for feeling how an interface changes across widths. Drag the simulated viewport from pocket to desktop, adjust the hero share and breathing room, change its material, then pin two compositions and compare them with a live wipe overlay. It is a direct-manipulation instrument, not an evaluation or score.

## Privacy-safe inspiration

The generic inspiration was the craft of interaction polish: responsive behavior, visual alignment, and checking that an interface remains intentional through changing states. Foldline contains no people, organizations, real projects, conversations, analytics, or private source material.

## How to open

Open `index.html` in any modern browser. No server, package installation, account, or internet connection is needed.

## Controls

- Drag **Viewport width** to move the specimen through pocket, balanced, and wide compositions.
- Adjust **Hero share** and **Breathing room** to change the internal balance.
- Pick **Acid**, **Coral**, or **Aqua** material.
- Select **Pin A**, change the composition, then select **Pin B**.
- Select **Compare** and drag the comparison wipe to inspect both pinned moments.
- **Copy CSS recipe** copies the current responsive values as a compact local snippet.
- **Try a composition** loads one of three deliberately different arrangements.
- **Reset** restores the original desk. Sliders support keyboard arrow keys.

## Why it was built

Responsive design is often experienced as numbers typed into inspector fields. Foldline makes the transition itself the object: a tactile little future app for watching hierarchy, rhythm, and density move together. It was built to feel like a useful dreamed tool rather than another themed information page.

## Format choice

- **Lane:** future artifact / product prototype — a real-feeling interactive design tool.
- **Mechanic:** direct manipulation of a responsive layout stage, with viewport bending, internal split and spacing controls, two pinned states, and an onion-skin wipe comparison. The copied CSS recipe is a real local output.

The artifact includes no real names, organizations, emails, phone numbers, addresses, financial data, credentials, exact conversation quotations, or sensitive details. It makes no network requests and stores nothing persistently; pinned states remain only in the current browser tab.
