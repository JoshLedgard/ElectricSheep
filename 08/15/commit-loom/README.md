# Commit Loom — A Tactile Repository Time-Lapse

*Daily Surprise · 2026-08-15*

## What it is

Commit Loom is a self-contained repository activity visualizer. It turns files into horizontal cloth bands and commits into colored, raised knots, then lets you scrub or replay the work as it accumulates over time. Tap a commit to inspect its subject and file changes, filter by author or path, reorder the bands, and export the current filtered view as a real SVG or PNG.

A rich, wholly fictional sample log is loaded at startup, so the interaction is ready immediately. You can also paste output from the clearly displayed `git log` command. Parsing and rendering happen only in the current browser tab.

## Privacy-safe inspiration

The generic inspiration was the rhythm of code review, project completion, and repository activity. That broad operational theme became a tactile way to see how software changes accumulate without using any real repository, organization, project, issue, person, message, conversation, or source data.

The included sample is invented and neutral. Commit Loom makes no network requests, has no analytics or account, uploads nothing, and does not persist pasted data.

## How to open

Open `index.html` in any modern browser. No server, package installation, build step, account, or internet connection is required.

## Controls

- Drag the **Shuttle** slider, the top ruler, or horizontally across the cloth to scrub through commits.
- Tap **Weave** to play the repository time-lapse; use previous, next, rewind, and speed controls to navigate it.
- Tap a visible commit column or select one in the text commit list to inspect its details.
- Toggle fictional authors, filter bands by file path, and order bands by first touch, activity, or name.
- Open **Weave your own log** to copy the supported command and paste its output. Author email addresses are discarded during parsing.
- Use **Export SVG** or **Export PNG** to download the exact filtered view and shuttle position currently shown.
- Keyboard: Space plays or pauses; Left/Right steps; Home/End jumps to the beginning or end.

## Why it was built

Repository histories are usually read as lists. Commit Loom asks what becomes visible when the same history behaves like a physical object: strands accumulating, hands leaving distinct marks, and bursts of work appearing as texture. It is a real local utility wrapped in a deliberately unusual tactile interface—not a grade or status report.

## Format choice

- **Lane:** `data_visualization` — presented as a polished, real-feeling local tool and future artifact.
- **Mechanic:** paste or load git-log text, then scrub and play a touch-driven woven time-lapse; inspect commits, filter authors and file paths, reorder the bands, and export the current visualization as a genuine SVG or PNG.

This lane and interaction differ from the previous screenshot-redaction workbench, prose-rhythm editor, and responsive-layout studio.

## Privacy check

- No real people, organizations, repositories, projects, issues, accounts, emails, addresses, financial details, private conversations, or source logs are included.
- Sample identities, filenames, hashes, dates, and commit messages are fictional and generated locally.
- No network requests, external assets, storage, uploads, analytics, credentials, or tokens are used.
