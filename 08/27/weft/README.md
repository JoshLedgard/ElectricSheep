# Weft — A Landing-Page Motion Loom

*Daily Surprise · 2026-08-27*

## What it is

Weft is a self-contained motion-composition instrument for a fictional landing page. Pull four colored timing threads across a twelve-second loom to decide when the headline, supporting proof, visual demo, and action appear. Scrub the playhead, watch the composition perform inside a phone-sized stage, edit the copy and colorway, then export the result as a genuine standalone HTML page.

The included LILT composition is wholly fictional. Weft works locally and makes no network requests. It has no account, server, analytics, persistence, uploads, camera, microphone, or external assets.

## Privacy-safe inspiration

The broad inspiration was the generic craft of polishing an interface, making communication clearer, and turning review feedback into visible improvements. The artifact does not use or refer to any real person, organization, employer, product, project, customer, account, message, conversation, or source dataset.

## How to open

Open `index.html` directly in any modern browser. No install, package, build step, or server is required.

## Controls

- **Drag a colored thread** left or right to set that element’s entrance time.
- **Keyboard:** focus a thread and use the left/right arrow keys for fine timing changes.
- **Play / Pause** performs the full twelve-second page.
- **Timeline slider** scrubs to any instant.
- **Headline, proof line, and action** fields update the preview immediately.
- **Colorway** changes the fictional page theme.
- **Reset** restores the original composition.
- **Export HTML** downloads a real, self-contained page preserving the current words, theme, and timing.

On systems that request reduced motion, exported transitions are shortened to near-instant while the editing interface remains fully usable.

## Why it was built

Most page builders treat animation as decoration added after layout. Weft treats time as a first-class design material: a small message can be rehearsed as rhythm, adjusted by touch, and carried away as a working artifact. It is intentionally closer to a musical instrument than a checklist.

## Format choice

- **Lane:** `startup_growth_experiment` — presented as a polished future artifact and real-feeling product prototype.
- **Mechanic:** direct kinetic composition: edit a compact fictional product message, drag four timing threads on a tactile visual loom, scrub or play the resulting twelve-second landing-page performance, and export a genuine standalone HTML rendition.

This is structurally different from the recent direct printmaking, screenshot-perception, and gesture-recording instruments: its primary material is temporal choreography and its useful output is an executable page.
