# Soft Circuit — A Pocket Foley Looper

*Daily Surprise · 2026-08-16*

## What it is

Soft Circuit is a self-contained browser instrument with six tactile material pads: paper, glass, wood, rain, spring, and ember. Each pad produces a procedural Web Audio voice and a matching visual response. A seeded demo loop makes it ready to play immediately; you can perform freely, record and overdub an eight-beat loop, undo or clear hits, reshape tempo and texture, and export the current performance as a real PNG loop card.

It is an instrument rather than a generic generator: the loop is built from direct taps and can preserve exact timing or snap new hits to a sixteenth-note grid.

## Privacy-safe inspiration

The broad inspiration was the rhythm of recurring work and the value of a small tactile decompression ritual after focused review. That generic theme became a fictional pocket device without using any real person, organization, project, message, conversation, account, or source material.

Everything runs in the current browser tab. Soft Circuit has no network requests, external assets, account, analytics, persistence, upload, microphone, camera, or recordings. All sound is synthesized locally after a user gesture.

## How to open

Open `index.html` in any modern browser. No server, installation, package, account, or internet connection is required. Select **Wake the device** for audio plus the seeded loop, or **Enter muted** for visuals only.

## Controls

- Tap/click the six material pads, or use number keys **1–6**. Strike higher on a pad for a harder hit and lower for a softer one.
- **Play** starts or stops the eight-beat loop.
- **Rec** starts playback if needed and arms overdub; each performed hit is added to the loop.
- **Undo** removes the latest recorded hit. **Clear** uses a two-tap confirmation.
- **Grid** switches between sixteenth-note quantization and exact free timing.
- Adjust **Tempo**, **Texture**, **Air**, and **Level** with touch-friendly controls.
- **Mute** silences audio while keeping the visual performance running.
- **Seed** restores the fictional demo loop.
- **Loop card** exports a genuine PNG snapshot showing the ring, material mix, settings, and loop fingerprint.
- Keyboard shortcuts: **Space** play/stop, **R** record, **M** mute, **Z** undo, and **E** export.
