# Echo Test — A Pocket First-Impression Studio

*Daily Surprise · 2026-08-26*

## What it is

Echo Test is a self-contained pocket first-impression study. A host prepares a small fictional product specimen, hands the device to a participant, and gives them exactly five seconds to look. Once the specimen disappears, the participant sketches the layout they remember and enters a few words that stuck.

Run up to three ephemeral takes, then reveal the original underneath the independent memory traces. The result is deliberately not a grade, benchmark, winner, or recommendation: it is a visual conversation artifact showing what survived a very short encounter. The current overlay can be downloaded as a genuine local SVG memory print.

Everything runs in the current browser tab. There are no dependencies, external assets, network requests, accounts, analytics, persistence, uploads, camera, microphone, location access, or clipboard reads. Session data disappears on reset or when the page closes.

## Privacy-safe inspiration

The broad inspiration was the generic craft of careful product review and turning a subjective first impression into something visible and discussable. That theme became a fictional local research device without using or referring to any real person, employer, organization, product, project, customer, account, message, conversation, or source data.

## How to open

Open `index.html` in any modern browser. It works directly from `file://`; no server or installation is required. It is designed mobile-first and also works with a mouse and keyboard.

## Controls

1. In **Host**, edit the eyebrow, headline, supporting text, and action label, or keep the invented demo specimen.
2. Tap **Begin a take**, hand over the device, and let the participant start the five-second exposure.
3. After the specimen vanishes, draw remembered regions directly on the recall pad. Add up to five remembered words. Keyboard users can move the drawing cursor with the arrow keys, lower or lift it with Space, and undo with U.
4. Submit the take, then repeat for up to three participants or reveal the overlay early.
5. Switch the reveal between specimen, traces, and both. Download **Memory print** to save a local SVG, or reset the session with the two-tap safeguard.

The exported SVG can contain the host's locally entered specimen text and participants' locally entered words and sketches. Review that content before sharing the file.

## Why it was built

Many product discussions begin with opinions about what is prominent. Echo Test makes a tiny real human observation possible on one device, without pretending that the result is a scientific evaluation or turning it into a score. It is a plausible little instrument for asking a sharper question: after five seconds, what was actually left in memory?

## Format choice

- **Lane:** `startup_growth_experiment` — presented as a polished future artifact and genuinely usable local product-research tool.
- **Mechanic:** timed five-second human exposure followed by freehand spatial recall and short keyword recall; up to three ephemeral takes become a direct visual overlay with local SVG export.

The interaction differs from the previous three surprises' tactile printmaking, screenshot-perception manipulation, and recent direct-manipulation instruments. It uses temporal human participation rather than a generator, board, map, simulation, or scoring system.

## Explicit bans avoided

Echo Test is **not** a field guide, atlas, almanac, codex, bestiary, zine, or pocket guide; not a choose-your-own or branching adventure, microquest, or multiple-ending story; not a signal, cartography, constellation, routing, or path-connection metaphor; not a launch, readiness, shipping, or preflight simulator; not a scorecard, rubric meter, benchmark, ranking, or winner selector; not an abstract AI-agent context/prism/debugger; and not a poetic generator.

## Privacy check

The built-in specimen copy is invented. The artifact contains no real names, emails, phone numbers, addresses, employers, customers, account details, financial data, private quotes, secrets, or credentials. It does not persist or transmit entered text or drawings. User-entered content exists only in browser memory and may appear in a locally downloaded SVG when the user explicitly exports it.
