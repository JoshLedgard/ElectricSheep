# Copyglass — A Microcopy Pressure Lab

*Daily Surprise · 2026-08-08*

## What it is

Copyglass is a self-contained microcopy workbench that shows what short interface text does when real UI constraints squeeze it. Edit harmless fictional copy, drag the specimen frame narrower, enlarge the type, or simulate language expansion. Copyglass measures the rendered DOM and identifies actual wrapping, truncation, and clipped text across a button row, toast, notification, and share card—without turning the work into a score.

Three fictional example sets make the app useful immediately. A plain-text snapshot captures the current rig settings, source copy, rendered expansion, and concrete findings for a design or writing handoff.

Everything runs locally in the open browser tab. There are no accounts, uploads, analytics, network requests, external assets, packages, saved browser data, or server.

## Privacy-safe inspiration

The generic inspiration was the craft of refining short product text across several software surfaces and discovering that wording which looks comfortable in one place can strain somewhere smaller. That broad product-writing theme became a tactile, browser-local pressure lab. Copyglass contains no real people, organizations, projects, campaigns, conversations, messages, credentials, or private source text.

Custom text remains only in the current browser tab unless the user explicitly copies a snapshot.

## How to open

Open `index.html` in any modern browser. No installation, build step, package manager, or server is required.

## Controls

- Edit copy under **Words**, switching among button, toast, notification, and share-card fields.
- Drag either striped edge of the specimen frame to change its real rendered width. The arrow keys also work when an edge grip is focused; hold Shift for larger steps.
- Use **Type size** to enlarge or reduce the specimens.
- Select a language-expansion setting to preview deterministic text growth without calling a model or translation service.
- Read **Glass notes** for concrete wrap, clipping, and truncation observations; switch between strained items and all items.
- Use **Another fictional set** to rotate the harmless sample copy.
- Use **Copy snapshot** or **Show snapshot text** to capture the current state for a handoff.

## Why it was built

Short copy is part language and part physical material. A character can be harmless in a document and decisive inside a narrow control. Copyglass makes that pressure visible in the same place the words are edited, helping a writer or product builder reason from actual interface behavior rather than a character count alone.

## Format choice

- **Lane:** `writing_or_decision_aid` — implemented as a polished practical micro-tool and believable product prototype.
- **Mechanic:** edit fictional interface copy, then directly manipulate real DOM constraints by squeezing width, scaling type, and applying deterministic language expansion; inspect measured overflow/wrap states across multiple UI surfaces and copy a plain-text snapshot. There are no grades, points, generated prose, or prescribed answers.

This interaction is structurally different from the recent direct-manipulation folding game, textile diff visualization, and timed recall painting.
