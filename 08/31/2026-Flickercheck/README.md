# Flickercheck — A Change-Blindness Arcade

*Daily Surprise · 2026-08-31*

## What it is

Flickercheck is a self-contained perception arcade built like a fictional pocket test instrument. Two nearly identical invented interface specimens alternate in place; exactly one element changes, and your job is to tap it before the clock expires. The deterministic run includes more than ten increasingly subtle rounds, streaks, limited retries, manual A/B flipping, pause/reveal controls, keyboard targeting, and a completion state.

Flickercheck is a short observation game, not a test or measurement of eyesight, cognition, health, or ability. All panels and readings are fictional.

Everything runs in the current browser tab. There are no external assets, network requests, accounts, analytics, persistence, uploads, camera, microphone, or dependencies.

## Privacy-safe inspiration

The broad inspiration was the generic craft of returning to changing work, verifying what actually changed, and separating meaningful differences from background noise. Flickercheck does not use or refer to any real person, organization, employer, project, product, customer, account, report, conversation, metric, or source dataset.

## How to open

Open `index.html` directly in any modern browser. No install, build step, package, or server is required.

## Controls

- **Start bench** begins the deterministic round sequence.
- **Tap or click** the element that changed between frame A and frame B.
- **Auto flick / Flip A/B** toggles automatic alternation or manual comparison.
- **Pause** stops the clock; leaving the browser window also pauses play.
- **Reveal** shows the changed region and records the round as revealed.
- **Calm mode** slows the alternation and reduces motion.
- **Keyboard:** arrow keys move a visible crosshair, Shift + arrows make fine adjustments, Enter commits, `F` flips frames in manual mode, `P` or Escape pauses, and `R` reveals.

## Why it was built

Change blindness is a surprising, tactile mechanic that turns careful review into a compact game. The interaction is structurally different from recent creative instruments: the output is not generated or composed; success comes from noticing one real temporal difference and pointing to it.

## Format choice

- **Lane:** `game_or_puzzle` — presented as a polished future artifact and fictional perception-training device.
- **Mechanic:** rapid temporal A/B flicker with direct changed-target hit testing, escalating deterministic rounds, manual frame flipping, retries, streaks, and keyboard crosshair targeting.

This deliberately avoids the recent map/explorer, card-board, generator/forge, tactile composition, and motion-loom patterns.
